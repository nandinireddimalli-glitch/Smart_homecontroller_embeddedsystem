# 📱 Smartphone Controller System

## 📌 Overview

The Smartphone Controller System is an IoT-based project that allows users to control electronic devices remotely using a smartphone. The system provides a convenient way to operate connected devices through a mobile application.

## ✨ Features

- 📱 Smartphone-based device control
- 🔌 Remote ON/OFF control
- 🌐 IoT-enabled communication
- ⚡ Real-time control of connected devices
- 💡 Simple and user-friendly interface
- 🔧 Easy to expand for multiple devices

## 🛠️ Technologies Used

- Arduino / ESP32
- IoT
- Smartphone Application
- Embedded C / C++
- Sensors and electronic components

## ⚙️ Working

1. The microcontroller is connected to the required electronic devices.
2. The smartphone application sends control commands.
3. The microcontroller receives the commands through the communication network.
4. Based on the received command, the connected device is turned ON or OFF.
5. The user can control the system remotely using the smartphone.

- IoT-based Automation
